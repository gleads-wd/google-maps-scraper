## 告别逐条复制 Google 地图商家信息

GLeads 是一款浏览器插件，用于采集 Google 地图搜索结果中公开展示的商家信息。搜索行业和地点、启动 GLeads，即可将去重后的结果导出为 CSV 或 Excel。

无需 Google Maps API Key。

## 主要功能

- 自动滚动当前 Google 地图结果列表
- 支持开始、暂停、继续和重置采集
- 使用 Google Place ID 去除重复商家
- 提供 20 多个可选导出字段
- 导出 CSV 或 XLSX
- 可在结果列表到底后自动下载
- 在浏览器本地处理已采集的商家信息
- 支持英文和简体中文界面

## 使用方法

![搜索 Google 地图、采集商家并导出线索](./docs/images/how-it-works.png)

1. **[安装 GLeads Chrome 插件](https://gleads.wadesk.io/cn/google-maps-scraper-chrome-extension?utm_source=github&utm_medium=referral&utm_campaign=google-maps-scraper&utm_content=how-to-use-zh)**。
2. 打开 [Google 地图](https://www.google.com/maps)，搜索行业和地点，例如 `dentists in Austin`。
3. 打开 GLeads 面板并开始采集。
4. 等待插件自动加载结果，也可以随时暂停或继续。
5. 选择所需字段，将去重后的记录导出为 CSV 或 Excel。

## 可采集的商家字段

具体字段取决于商家在 Google 地图中公开提供的信息。

- 商家名称和分类
- 完整地址、街道和城市
- 主要电话和其他电话号码
- 官方网站和域名
- 平均评分和评价数量
- 评价链接和 Google 地图链接
- 经纬度
- 营业时间
- 认领状态和封面图片
- Place ID、CID、Plus Code 和 KGMID
- Google 知识图谱链接
